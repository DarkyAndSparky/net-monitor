ARP-таблица и соседи MikroTik

ARP-таблица показывает все IP/MAC, которые роутер видел в своей сети, с указанием порта. MNDP-соседи — устройства MikroTik/RouterOS, обнаруженные напрямую (имя, платформа, порт). «Построить топологию» использует оба источника и рисует реальные связи на карте вместо условной звезды.

Добавить подключение

Опционально — заполните, если включён модуль «Мониторинг трафика». Имена интерфейсов как в WinBox (например ether1)

MikroTik: требуется включённый API-сервис (IP → Services → api, порт 8728, либо api-ssl 8729).

UniFi: логин/пароль локального администратора контроллера. Порт по умолчанию зависит от типа консоли — 443 для UniFi OS (UDM/UDM Pro/Cloud Key Gen2+), 8443 для классического software-контроллера или Cloud Key Gen1 (самая частая причина «не подключается» — неверный порт). Самоподписанный сертификат контроллера принимается автоматически. Импортируются и инфраструктура (точки доступа/свитчи/шлюзы), и подключённые клиенты.

Cisco: подключение по SSH, выполняется команда show ip arp. Нужен пользователь с правом просмотра (privilege level 15 надёжнее всего). Работает для большинства IOS/IOS-XE с включённым SSH.

Устройства из импорта попадают в реестр с пометкой источника; мониторинг для них по умолчанию выключен — включите нужные во вкладке «Мониторинг».

Категории устройств

Категории используются в дешборде, фильтрах, цветах на карте и облаках подсетей. Нельзя удалить категорию, пока на неё ссылается хотя бы одно устройство — сначала перенесите их в другую.

Добавить пользователя

Operator: устройства, карта, мониторинг, обнаружение сети, алерты, категории — без доступа к пользователям, брендингу, резервным копиям, фиче-флагам и учётным данным интеграций.

Роль «Только просмотр» — доступ к дешборду, устройствам, карте и мониторингу без возможности что-либо менять: без добавления/редактирования/удаления устройств, без настроек, без обнаружения сети.

Функции (дополнительные модули)

Каждый модуль выключен по умолчанию — включайте только то, что реально нужно, чтобы не грузить сеть и сервер лишним опросом.

Резервная копия

Полный снимок данных (устройства, пользователи, настройки, история, топология, инциденты, аудит-лог) в одном JSON-файле. Секрет сессии в бэкап не входит — он привязан к конкретной инсталляции.

Внимание: восстановление полностью заменит текущие данные (устройства, пользователей, настройки и т.д.) содержимым файла. Действие необратимо — сначала скачайте текущий бэкап, если не уверены.

Импорт устройств из CSV

Формат: первая строка — заголовок с колонками name,ip,mac,location,type,category,comment (обязательны только name и ip). Категория — один из id: network, server, workstation, cctv, other.
